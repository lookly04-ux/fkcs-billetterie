Hébergement GitHub Pages + Firebase (3–4 téléphones)

En test local ou sur un même appareil/navigateur, la synchronisation fonctionne immédiatement entre onglets via BroadcastChannel et localStorage.

Pour connecter 3 ou 4 téléphones différents en ligne depuis GitHub Pages, branchez votre configuration Firebase Realtime Database / Firestore dans le bloc FIREBASE_CONFIG du fichier.
